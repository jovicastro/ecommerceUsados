🛍️ eCommerceUsados
Projeto de uma loja online para compra e venda de produtos usados, com funcionalidades básicas 🧱.

🚀 Funcionalidades
Cadastro e autenticação de usuários 🔐

Listagem de produtos usados com fotos 📸

Adição de produtos ao carrinho

Finalização de compra

⚙️ Tecnologias
Backend: Node.js + Express

Banco de dados: (por exemplo) MongoDB ou PostgreSQL

Frontend: React / Vue / Angular (ajustar conforme o projeto)
